# 그래픽·사운드·AI 에셋 가이드
## 아트 방향
준실사, 실제 종의 실루엣/크기/색/행동을 유지하고 조명과 색감에 예술적 자유 허용. 그레이트 배리어 리프의 건강한 생태계를 기본으로 표현. 과도한 채도, 생물 왜곡, 피/사체/공포 연출 지양.

| 환경 | 표현 목표 |
|---|---|
| 산호초 | 다양한 산호 형태와 군집, 얕은 수역 빛 |
| 모래 해저 | 완만한 지형, 모래 무늬, 저서 생물 |
| 암벽 | 수직 구조, 틈새, 수심별 조명 |
| 개방 수역 | 거리 안개, 대형 생물, 군집 |
| 동굴 | 안전한 이동 공간, 낮은 조도 |
| 해초 군락 | 해류 연동 흔들림, 저서 서식지 |

## URP 효과
수중 안개, God Rays, Caustics, 부유 입자, 수면, 수심별 색흡수, 시간/날씨 조명, 해류 연동 식생. Shader Graph/HLSL 및 승인 에셋 사용. 실제 빛 전달의 근사 표현이며 과학적 정밀 시뮬레이션 아님. 효과별 품질 옵션, 투명 오버드로 및 GPU 비용 측정. VR 호환 셰이더는 후속 검증.

## 생물 제작
기존 무료/유료 모델, AI 생성, 직접 제작 혼합. Meshy/Tripo AI, Blender, 이미지 생성 도구 등은 후보. 참조 자료 → 생성/모델 확보 → 종 외형 검수 → 토폴로지/UV/텍스처 → 리깅/애니메이션 → Unity 임포트 → 스케일/LOD/충돌/URP 검증. 기본 클립과 절차적 꼬리/지느러미/몸체 보정 혼합. 고정 생물은 셰이더 기반 움직임 후보. 폴리곤/텍스처 예산은 성능 측정 후 확정.

## 음향
실제 녹음 자료 우선(종 소리), 환경음/효과음/힐링 음악은 기존 에셋 및 AI 생성 병행. Suno/Udio 등은 후보일 뿐 사용 확정 아님. Audio Mixer 그룹 Master/Music/Ambience/Creature 제안, 거리 감쇠, 저역 필터, 수심/날씨/행동 연동, Crossfade. 실제 녹음과 합성음을 구분. 음향 발생 근거가 없는 생물에 임의 울음소리 부여 금지.

## 에셋 승인 체크
원본 URL/제작자/도구/생성일/라이선스/배포 권한/수정 내역/종 검증/성능 검증 기록. AI 생성 서비스 약관과 상업적 배포 조건 확인. 유료 구매 및 외부 업로드 승인 필요. 미검증 에셋은 프로토타입 한정 표시 및 배포 제외. 실제 에셋 목록과 예산 미정.

## M5 프로토타입 출처 기록

수면 무늬, 해초 움직임, 부유 입자와 천해 조명은 프로젝트에서 작성한 셰이더와 Unity 기본 기능을 사용한다. 꼬리와 지느러미는 기존 임시 메시를 개체 이동 속도에 맞춰 회전시킨다. 물소리와 두 음악 루프는 코드로 합성한 임시 음향이다. 종의 실제 발성이나 현장 녹음으로 표시하지 않는다. 외부 배포용 음원과 모델의 라이선스 검증은 해당 에셋이 추가될 때 진행한다.
