# 마일스톤 개발 계획
기간 미지정. 각 단계는 실행 가능한 결과물, 테스트 결과, 사용자 승인으로 종료. 아래 세부 배치는 구현 제안이며 기획 범위 변경은 승인 필요.

| 단계 | 작업 | 완료 조건 |
|---|---|---|
| M0 | Unity/URP/Git/폴더/문서/패키지 검증, 테스트 환경, 기본 씬 | 지정 버전 실행, 컴파일, 빈 PC 빌드 또는 미실행 사유, 사용자 승인 |
| M1 | F01/F11 기초 수중 씬, 카메라, 이동, 충돌/경계, 입력 | 자유 유영 및 수심 이동, 조작 검증, 기본 성능 기록 |
| M2 | F04/F05 대표 5종 후보 검증 및 승인, 데이터/FSM/Boids/접근 반응 | 종별 행동 재현, 군집/풀 초기 테스트, 데이터 검증 |
| M3 | F02/F03 6개 서식지, 500×500m, 수심 0~150m, 환경 시계/날씨/계절/해류 | 구역 이동, 환경 모드 전환, 오프라인 동작 |
| M4 | F04~F06 30종, 구역 스폰, 공생/추격/도피, 자연 이벤트 | 종 목록 승인 및 출처 확인, 팝인/개체 상한 검증, 실제 포식 없음 |
| M5 | F11/F12 수중 효과, 혼합 애니메이션, 공간 음향 | 시각/음향 리뷰, 라이선스 기록, 품질별 성능 측정 |
| M6 | F07~F09 도감/일지/사진/앨범 | 자동 관찰, 메모 CRUD, 촬영/분류/내보내기, 오류 처리 |
| M7 | F10/F13 힐링, 자동 경로/추적, 지도/메뉴/설정 | 모드 전환, 경로 복귀, UI 토글, 타이머 검증 |
| M8 | F14/F15 저장/복구/마이그레이션, 한국어/영어 | 재실행 복원, 손상 복구, 번역 누락 검사 |
| M9 | 전 기능 QA, 최적화, 접근성, PC 빌드 | 테스트 계획 충족, 기준 장비 승인, 성능 보고, 차단 결함 없음 |
| M10 | itch.io 테스트 → Steam 무료 출시 | 피드백 반영, 배포 권한/라이선스/스토어 요건 확인, 사용자 공개 승인 |
| M11 | F16 PC VR 후 독립형 VR 확장 검토 | 실제 기기 테스트, 조작/멀미/성능/플랫폼 요건 검증, 사용자 승인 |

## 선행 작업 및 운영
M0에서 데이터 ID/저장 인터페이스/Localization 키 기본 구조를 마련하고 각 기능에서 필요한 저장 및 테스트를 함께 구현한다. M8은 통합 검증 단계이지 저장을 처음 구현하는 단계가 아니다. M1부터 성능 기준선을 기록하고 M9에서 최종 최적화. 에셋 라이선스 및 생물 자료 검증은 확보 시점부터 수행. 대표 종 5종과 30종 전체 목록은 M2/M4 이전 승인. VR 기기 없음은 M11 출시 차단 조건이며 시뮬레이터만으로 승인하지 않는다.

## Codex 최초 요청 예시
`AGENTS.md와 README.md 및 DEVELOPMENT_PLAN.md를 읽고 M0 작업 계획을 제시해. 기존 프로젝트와 Unity 버전을 먼저 확인하고, 패키지 추가나 설정 변경은 승인 전 수행하지 마. M0 완료 후 테스트 결과와 미검증 항목을 보고하고 다음 단계는 시작하지 마.`

## 변경 관리
요구사항 ID, 변경 이유, 영향 문서/코드/테스트, 승인 여부 기록. 작업 상태는 Not started/In progress/Blocked/Review/Approved 후보. 일정이나 비용 추정은 실제 진행 데이터 확보 후 제시.
