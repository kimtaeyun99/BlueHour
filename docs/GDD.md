# Blue Hour — 콘텐츠 기획서
## 1. 정체성 및 목표 (확정)
실제 바닷속에 들어간 듯한 몰입, 살아 움직이는 바다, 우연한 발견, 자연스러운 학습을 핵심으로 한다. 휴식과 교육을 함께 제공한다. 게임의 승패, 성장, 경쟁, 산소/HP/압력 피해, 죽음, 시간 제한은 없다. 생물에게 먹이를 주거나 만지지 않으며 생물이 사용자를 공격하지 않는다.

## 2. 체험 흐름
실시간 해양 배경 메뉴 → 해양 체험 또는 힐링 감상 → 자유 유영/자동 감상 → 생물 관찰 및 선택적 정보 열람 → 사진/일지 → 종료 및 자동 저장 → 재방문. 도감 전체는 처음부터 열람 가능하고 관찰 여부만 기록한다. 사진 점수나 수집 보상 없음.

## 3. 월드
초기 월드는 호주 Great Barrier Reef 기반 재구성으로 실제 지형의 정밀 복제는 아니다. 500×500m, 0~150m 깊이, 산호초/모래 해저/암벽/개방 수역/수중 동굴/해초 군락. 자연 지형과 안개 및 점진적 이동 제한으로 경계를 표현한다. 1 Unity unit=1m는 제안 기준. 독립 월드 구조로 신규 해역 확장.

## 4. 환경 및 생태계
실제 현지 시각(시스템 시계, Queensland UTC+10) 기본, 가속/고정 시간 선택. 실제 계절 및 사용자 지정 계절. 날씨는 내부 시뮬레이션 또는 수동 설정. 온도, 염분, 압력, 해류, 빛을 데이터 기반으로 표현하되 정밀 물리/기후 예측 모델은 아님. 생물의 활동, 분포, 출현, 행동이 환경에 반응한다.
30종 목표: 어류 12, 상어/가오리 4, 해양 포유류 2, 파충류 2, 기타 무척추 4, 산호 4, 해초/조류 2. 실제 종 목록은 분포·에셋 검증 후 승인. 개체 크기/색/속도/경계심 변이. 성장, 배고픔, 피로, 번식 욕구, 개체 사망 시뮬레이션 없음. 포식은 추격/도피만 표현. 공생 대표 사례, 군집 Boids, 서식지별 이동. 사용자 접근 반응은 무시/경계/회피/호기심. 환경 기반 개체수 변화 및 확률 출현, 자연 이벤트. 실제 관측 빈도와 체험용 확률을 구분한다.

## 5. 교육 및 힐링
외형/크기, 행동, 먹이망/공생, 분포/서식지, 수심, 온도/염분/압력, 빛, 일주기, 계절/이동, 소리, 환경 변화, 학명 및 출처를 교육·표현 범위에 포함. 자동 관찰 등록, 최초 발견 날짜/해역/수심/시간대, 사용자 메모 CRUD, 사진 연결. 사진 모드 UI 숨김/줌/촬영, 앨범 열람/삭제/즐겨찾기/분류/내보내기. 힐링은 고정/자동 유영/생물 추적, 지정 경로와 동적 관찰 우회, 환경/속도/음악 조절, 무제한 및 종료 타이머.

## 6. 출시 범위
PC 우선, itch.io 테스트 → Steam 무료 출시, 한국어/영어. 무료 업데이트로 기존 해역 개선 및 신규 해역 추가. 이후 PC VR, 독립형 VR은 기기 및 플랫폼 검증 조건부. VR은 자유 유영/순간이동, Smooth/Snap Turn, 착석/기립, 컨트롤러 상호작용, 멀미 방지 설정. 환경 변화 별도 체험(백화/오염 등)은 후속 확장 후보이며 교육적 시나리오로 한정. 수족관/터널/관측실/잠수정/생물 시점은 후속 후보. 움직이는 배경화면 및 화면 보호기는 전체 제외.

## 7. 미결정
종 목록, 지형 배치, 에셋 예산, 관찰 거리/시간, 출현 확률, 성능 기준 장비, VR 기기, 확장 순서, 구체적 출시일은 승인 및 검증 후 확정.
