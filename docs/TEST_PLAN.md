# 테스트 및 품질 검증 계획
## 원칙
자동화 가능한 순수 로직은 EditMode, Unity 생명주기/씬/입력은 PlayMode, 그래픽/음향/조작은 실제 빌드 수동 테스트. 모든 결과는 Pass/Fail/Not run과 재현 절차, 환경, 로그로 기록. 실행하지 않은 테스트를 통과로 보고하지 않는다.

| ID | 대상 | 검증 및 기대 결과 |
|---|---|---|
| T01 | F01 | 이동 6방향, 충돌, 경계, 시점 전환; 지형 관통/강제 사망 없음 |
| T02 | F02/F03 | 6구역 식별, 수심 범위, 현지 시각/가속/고정, 계절/날씨 전환, 네트워크 차단 상태 동작 |
| T03 | F04/F05 | ID 중복/범위/참조 검증, FSM 전이, 군집 거리, 접근 반응, 추격 종료, 고정형 이동 없음 |
| T04 | F06 | 환경 부적합 종 미출현, seed 재현, 개체 상한, 풀 재사용 초기화, 가시 영역 팝인 수동 확인 |
| T05 | F07/F08 | 관찰 조건 경계값, 중복 등록 방지, 전체 도감 열람, 메모 CRUD 및 사진 연결 |
| T06 | F09 | UI 없는 캡처, 줌, 파일/메타 저장, 삭제/즐겨찾기/내보내기, 디스크 부족/권한 오류 |
| T07 | F10 | 3가지 감상 모드, 경로 우회/복귀, 대상 소실, 수동 취소, 타이머 만료 |
| T08 | F11/F12 | 수심/날씨/시간 효과, 애니메이션, 공간 음향, 음악 전환, 볼륨 및 무음 설정 |
| T09 | F13 | 메뉴/지도/HUD 토글, 입력 충돌, 해상도 변경, 글자 크기, 설정 적용 |
| T10 | F14 | 재실행 복원, 개체 상태 미저장, tmp 중단, 손상 JSON, bak 복구, 버전 마이그레이션, 잘못된 위치 안전 복귀 |
| T11 | F15 | 한국어/영어 전환, 누락 키/잘림/폰트, 학명 및 번역 검수 |
| T12 | F16 | 실제 기기별 이동/회전/착석/기립/포인터/멀미 옵션/프레임 검증; 기기 없으면 Not run |
| T13 | 출시 | 클린 설치, 오프라인 실행, 업데이트 후 저장 호환, 라이선스/출처, 공개 승인 |

## 성능 측정 (제안 프로토콜)
FHD 동일 빌드/품질/장비에서 산호초 밀집, 개방 수역 군집, 동굴, 자연 이벤트, 자동 감상, 메뉴 전환, 사진/저장 시나리오 측정. 워밍업 후 각 60초 이상 3회 반복 제안. 평균 FPS, 프레임 시간 p95/p99, CPU/GPU ms, GC.Alloc, 메모리, 활성 생물 수, draw calls 기록. 60 FPS 목표=16.67ms 프레임 예산; p95 등 최종 합격 기준 및 기준 하드웨어는 M9 전 승인. Editor 측정과 실제 빌드 측정 구분. 장시간 감상 테스트로 메모리 증가/풀 누수 확인. 최적화 전후 동일 조건 비교.

## 과학·아트·출시 QA
종별 실제 분포/학명/크기/서식/행동/소리 출처 검토. 교육용 근사와 예술적 연출 명시. AI 생성 및 라이선스 기록 확인. 차단 결함(실행 불가, 데이터 손실, 주요 기능 불능, 배포 권한 미확인)은 출시 전 해결. 실제 VR 기기 및 플랫폼 검증 전 VR 출시 승인 금지.

## 테스트 실행
Unity Test Runner에서 EditMode/PlayMode 실행. CLI 사용 시 설치된 Unity 실행 파일과 프로젝트 경로를 확인하고 `-batchmode -projectPath <path> -runTests -testPlatform EditMode -testResults <xml>` 형태를 버전 문서와 대조 후 사용. PlayMode도 별도 실행. 현재 문서 작성 단계에서는 Unity 실행 및 테스트를 수행하지 않았다.

## M9 Windows 프로토타입 검증 기록

2026-11-28에 Unity 6000.3.7f1에서 EditMode 38/38, PlayMode 10/10이 통과했다. Windows x64 일반 검증 빌드를 StrictMode로 생성했다. 가상 키보드로 F1, F2, F4, F5를 눌러 환경 패널, 시각 가속, 계절 및 날씨 설정이 변경되는 것을 확인했다. 실물 키보드 전체 조작은 별도 수동 검증 항목이다.

Windows 11, Ryzen 5 5600, RTX 4060, RAM 32GB 환경에서 FHD 창 모드, 정오·맑음·높음 프리셋으로 측정했다. 구역별 3초 워밍업 후 12초씩 한 차례 측정한 프로토타입 수치다.

| 위치 | 평균 FPS | p95 프레임 시간 | p99 프레임 시간 | 활성 개체 |
|---|---:|---:|---:|---:|
| 산호초 시작 구역 | 530.5 | 2.92ms | 3.57ms | 16 |
| 개방 수역 | 719.7 | 2.32ms | 2.85ms | 16 |
| 수중 동굴 | 516.9 | 2.70ms | 3.46ms | 16 |
| 해초 군락 | 550.7 | 2.79ms | 3.52ms | 16 |
| 경로 감상 | 659.8 | 2.49ms | 3.11ms | 16 |

M6의 촬영 검증은 별도 저장 프로필에서 FHD PNG 저장 후 다시 로드하는 데 629ms가 걸렸으며, M8은 Windows 실행 파일 재시작 후 언어·날씨·위치 복원을 확인했다. 최종 에셋 적용, 32개체 최대 부하, 장시간 플레이, CPU·GPU 별도 계측, 전체 번역·접근성 검수 및 출시 기준 장비 승인은 별도 단계로 남긴다.
