# 기능 명세서
아래 ID는 개발 계획 및 테스트 추적에 사용한다. 수치 미정 항목은 설정 가능한 데이터로 두고 사용자 승인 후 확정한다.

| ID | 기능 | 동작 및 인수 조건 |
|---|---|---|
| F01 | 자유 유영 | 1인칭, 상하/전후/좌우 이동, 시점 조절, 몸체/장비 없음. 지형 통과 방지, 자연 경계, 생존 제약 없음. |
| F02 | 월드 | 6개 서식 환경과 0~150m 수심을 가진 500×500m 해역. 구역 식별 및 확장 가능한 월드 선택. |
| F03 | 환경 | 현지 실시간/가속/고정 시각, 실제/지정 계절, 내부/수동 날씨. 수심별 온도/염분/압력/빛/해류 조회. 오프라인 동작. |
| F04 | 생물 데이터 | 30종 정의, 대표 5종 우선. 종별 외형, 서식, 행동, 소리, 출처 연결. 개체 변이는 검증 범위 내. |
| F05 | 행동 | 유영/휴식/군집/먹이 탐색/추격/회피/공생/숨기/계절 이동을 종별 지원. 실제 포식/사망 없음. 접근 반응, 고정형 생물 지원. |
| F06 | 스폰 | 구역/시간/계절/환경/확률 기반 활성화 및 반환. 눈앞 팝인 최소화, 개체 수 상한 설정. 자연 이벤트는 조건 및 확률로 발생, 보상 없음. |
| F07 | 도감 | 모든 종 열람, 시선/거리/지속시간 조건 충족 시 최초 관찰 기록. 선택 시 이름/학명/요약, 확장 시 상세 및 출처. |
| F08 | 일지 | 최초 관찰 날짜/해역/수심/시간대 자동 기록, 메모 생성/수정/삭제, 사진 연결. 관찰 횟수/시간 통계 없음. |
| F09 | 사진 | 전용 모드 진입/종료, UI 숨김, 줌, 캡처. 파일과 메타데이터 저장. 앨범 열람/삭제/즐겨찾기/생물별 분류/내보내기. |
| F10 | 감상 | 고정/자동 유영/생물 따라가기 전환. 지정 경로에서 이벤트 관찰 우회 후 복귀. 대상 소실 시 안전한 복귀. 환경/속도/음악 설정, 선택형 종료 타이머. |
| F11 | 시각 | 준실사 URP, 안개/빛줄기/코스틱스/부유물/수심 색흡수/해초 움직임/동적 조명. 혼합 애니메이션. |
| F12 | 음향 | 환경·생물 연동 3D Audio, 자연음만/환경 음악/선택 음악, 개별 볼륨 및 자연스러운 전환. |
| F13 | UI | 실시간 배경 메뉴, 정보별 HUD 토글/전체 숨김, 호출 지도(현재 위치/수심/서식 구역, 생물 위치 제외 제안), 상세 설정. |
| F14 | 저장 | 설정/도감/일지/앨범/체험 상태 분리 JSON, 사진 별도 파일, 자동 저장, 백업 복구, 버전 관리. 개별 생물 상태 저장 금지. |
| F15 | 언어 | 한국어/영어 전환, UI/교육 문구 분리, 누락 키 검증. |
| F16 | VR 후속 | OpenXR 기반 후보, 자유 유영/순간이동, Smooth/Snap, 착석/기립, 레이 포인터/버튼, 시야 축소/가속/속도 조절. 실제 기기 검증 필수. |

## 예외 및 상태 전이 (제안)
- 체험 → 사진 → 체험: 이전 HUD 상태 복구. 메뉴/지도는 입력 충돌을 막고 닫으면 이전 모드 복귀.
- 자동 감상 → 수동: 즉시 사용자 제어권 반환. 경로 장애물/대상 소실 시 안전 경로 또는 고정 감상.
- 관찰 등록은 종 ID 기준 멱등 처리. 사진 저장 실패 시 성공 표시 금지. 삭제는 메타데이터 및 연결 일관성 유지.
- 저장 실패 시 기존 정상 파일 보존, 사용자에게 재시도 가능 안내. 로드 위치가 유효하지 않으면 안전 시작점 사용.
- 프로토타입에서 감상 타이머가 만료되면 메뉴로 복귀한다. 최종 동작은 이후 확정한다. 운영체제 종료는 범위 제외.
