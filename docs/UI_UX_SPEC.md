# UI/UX 설계서
## 원칙
몰입 우선, UI 최소화, 정보는 요청 시 표시. 키보드/마우스 PC 우선, VR은 별도 입력 어댑터. 한국어/영어, 글자 크기 조절, 색상만으로 상태 구분하지 않기, 명확한 포커스/뒤로가기. 화면 보호기 및 배경화면 메뉴 없음.

| 화면 | 구성 및 동작 |
|---|---|
| 메인 | 실시간 해양 배경, 해양 체험/힐링/도감/일지·앨범/설정/종료 |
| 체험 | 선택형 수심·수온·시간·위치·나침반, 전체 숨김, 메뉴 호출 |
| 생물 정보 | 선택 시 이름/학명/짧은 특징, 확장 시 분류/크기/분포/수심/먹이/공생/보전/출처 |
| 도감 | 전체 종 목록, 관찰 표시, 상세 정보. 잠금/보상 없음 |
| 일지 | 최초 관찰 정보, 메모 편집/삭제, 연결 사진 |
| 사진 | UI 숨김, 줌, 촬영, 종료. 성공/실패 피드백은 캡처 이미지에 포함하지 않음 |
| 앨범 | 썸네일, 상세, 즐겨찾기, 생물별 분류, 삭제 확인, 내보내기 |
| 지도 | 호출형, 현재 위치/수심/주요 지형/서식 구역. 생물 위치 숨김 제안 |
| 힐링 | 고정/유영/추적, 환경/속도/음악, 종료 타이머 |
| 설정 | 그래픽/해상도/FPS/그림자/거리/수중 효과, 음향 개별 볼륨, 키/감도/속도, 환경, UI 크기/표시, 접근성, 언어 |

## 입력 제안 (키 확정 전 검증)
WASD 이동, Space/Ctrl 상승·하강, 마우스 시점, Esc 메뉴/뒤로, M 지도, P 사진, H HUD 토글. 입력 재지정 및 충돌 검사. UI 열림 중 유영 입력 차단, 마우스 잠금 상태 복원. 자동 감상 중 사용자 취소는 즉시 제어권 반환. 사진 모드 줌은 FOV 조절 후보.

## VR 후속
World Space UI, 컨트롤러 레이/버튼, 머리 방향 기반 관찰(시선 추적 하드웨어 요구 없음). 착석/기립, 시점 높이, Smooth/Snap Turn, 순간이동/자유 유영, vignette/가속/속도 설정. 자동 카메라 이동은 멀미 위험을 검증하고 기본 비활성 또는 사용자 명시 선택을 제안. 강제 카메라 회전 금지. 실제 기기 검증 전 편안함 보장 금지.

## 미결정
와이어프레임, 색상/타이포, 기본 HUD 항목, 키 바인딩, 지도 표현, 타이머 만료 동작, 사진 해상도 및 접근성 세부값은 프로토타입 검토 후 확정.
